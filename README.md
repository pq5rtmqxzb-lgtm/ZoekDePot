# Ons Nieuwe Huis — ZoekDePot

A photoreal 3D walkthrough of apartment **type R3.sp, bouwnummer 25**
(Ypsilon Park, Den Haag). The apartment is generated by scripts in Blender
from the sales drawing, its lighting is baked (day / evening / night), and a
web viewer lets you walk through it in the browser, on a desktop or an iPad.

The site is the committed viewer build in `v2/site/`; Netlify publishes it
as-is, without a build step (see `netlify.toml`).

## How it works

```
data/model.json ──► v2/blender (Blender 4.5 as a Python module)
                      build_shell.py      walls, floors, ceilings, frames, sliding doors
                      build_furniture.py  furniture, kitchen, bathroom (v2/data/*.json)
                      bake.py             lightmaps per mood (cloud draft or laptop GPU)
                 ──► v2/web (Vite + TypeScript + three.js)
                      npm run assets      compress model + lightmaps
                      npm run site        build the viewer into v2/site/
```

Everything — how to build, bake (including on a laptop GPU), run the
viewer and test it — is in **[`v2/README.md`](v2/README.md)**. The plan
and the reasoning behind the choices are in
[`docs/modernization-plan.md`](docs/modernization-plan.md).

## Viewer controls

| | Desktop | iPad / touch |
|---|---|---|
| Walk | WASD / arrow keys (Shift: faster) | drag on the left half |
| Look around | mouse (click for pointer lock), Q/E | drag on the right half |
| Light | Dag / Avond / Nacht buttons (the baked moods) | same |

URL options: `?mood=evening`, `?quality=lite` (the iPad tier on a desktop),
`?pos=x,z,yaw,pitch` (start position, degrees).

## Checking the model against the drawing (`tools/`)

`data/model.json` was reconstructed from the PDF's vector lines. These
scripts (need `pymupdf` and `Pillow`) keep it honest:

```sh
python3 tools/compare-to-pdf.py   # measures every wall against the PDF vectors
python3 tools/plan-overlay.py     # overlays data/model.json on apartment.json
python3 tools/pdf-overlay.py      # draws the model over the PDF scan
python3 tools/render-floorplan.py # renders floorplan/floorplan.svg from apartment.json
```

Every wall lies within **0.12 m** of the drawing (columns report 0.25 m:
centreline versus slab face, as intended); door positions and swing
directions come from the PDF's door arcs. Rerun `compare-to-pdf.py` and
`plan-overlay.py` after any geometry change. CI (`.github/workflows/v2-shell.yml`)
checks the generated Blender model and the furniture layout on every push.
